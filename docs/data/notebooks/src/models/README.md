# Models

This directory contains documentation and configuration files related to the language models evaluated in this research.

## Evaluated Models

* BERT
* RoBERTa
* GPT-2

## Model Information

For each model, the project will document:

* Model architecture
* Pre-trained model used
* Configuration
* Fine-tuning approach
* Training parameters
* Evaluation metrics
* Computational requirements

Large pre-trained model files will not be stored directly in this repository unless their size and distribution requirements allow it.
