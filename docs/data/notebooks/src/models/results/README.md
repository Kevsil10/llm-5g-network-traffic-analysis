# Results

This directory contains the results obtained from the experimental evaluation of BERT, RoBERTa, and GPT-2 applied to 5G network traffic analysis.

## Evaluation

The models will be compared using the performance metrics defined in the research methodology.

These may include:

* Accuracy
* Precision
* Recall
* F1-score
* Training time
* Inference time

## Results Visualization

Graphs, tables, and other visualizations will be included to facilitate the comparison and interpretation of the experimental results.

## Model Comparison

The final analysis will summarize the experimental results and discuss the observed differences between the evaluated models.
